# 玩法、用户与商业模式

## 一次游玩循环

在城镇选择主控和队友，组成最多四人队伍。检查装备、技能、职业天赋与电路战术，进入已解锁的副本。小队面对普通怪群与首领，获得服务端确认的掉落与成长；回城整理配装、调整策略，再尝试更难的关卡。主控可以手动操作并与电路队友协作，也可在允许的副本模式让全队由电路控制。**四人队伍不等于四位玩家同步联网合作**，当前展示重点是同一玩家的角色小队。

## 八位英雄

| 英雄 | 角色风格与编队方向 |
|---|---|
| 烬 | 近身拳斗、爆发输出 |
| 霜 | 剑术与冰霜控制 |
| 岚 | 机动、位移与游击 |
| 胧 | 暗影镰刃、远近牵制 |
| 曜翎 | 法术与范围压制 |
| 磐玥 | 防御、承压与反击 |
| 铃铆 | 机械与火力覆盖 |
| 祈禾 | 治疗与队伍支援 |

上述是组合方向而非锁死职业。最终行为取决于已学技能、装备、职业／天赋、战术与场景。每个角色最多 20 个可装备技能格，另有普攻和防御；被动、主动、治疗、位移与持续效果按各自规则处理。界面支持比较装备变化，所有穿戴、升级、转职与重修仍受原生条件限制。

### English

The loop is prepare a squad → explore → fight → collect server-confirmed loot/progression → improve loadouts and tactics. Eight heroes support squads of up to four characters, not a claim of four human players in co-op. The current public early preview is Pass-gated and progression-limited; complete equipment/skill/profession/talent menus are on the research branch. Pass is a transferable gameplay-access NFT, not equity or yield. Planned cosmetics, seasonal content and challenges are prospective business directions, not promised earnings or already implemented NFT equipment trading. There is no claimed revenue/retention figure in this submission.
